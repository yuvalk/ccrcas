Claude Code Service - Configuration Directory
==============================================

This directory acts as HOME for the Claude Code service process.
The service reads OAuth tokens and settings from here instead of
a user profile directory.

DO NOT manually copy files here. Instead, run:

    .\authenticate.ps1 -ServiceUser "claude-svc"

The script handles the interactive Google OAuth sign-in and copies
the resulting tokens (including the refresh token) into this directory
automatically.

What gets stored here after authentication
------------------------------------------

  .claude/
    credentials.json   - OAuth tokens (access + refresh token)
    settings.json      - Claude Code settings
    auth.json          - Additional auth state (if present)

The OAuth refresh token allows Claude Code to obtain fresh access
tokens without a browser, so the service can authenticate on its own.

Re-authentication
-----------------

If tokens expire and auto-refresh fails, re-run authenticate.ps1.
Check the service logs for "401", "Token expired", or "Please log in".

After copying, verify that the service account has read access to
all files in this directory.
